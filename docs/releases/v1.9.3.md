# Painel Ping v1.9.3

- Frontend inicia somente após `/api/health` confirmar a API pronta, evitando recusas de conexão durante a inicialização do backend.
- Porta personalizada e `.env` do backend/raiz respeitados. Timeout de 60 segundos com instruções claras; processos encerram juntos.
- Dois dedos no touchpad navegam pelo mapa, mesmo com Mouse selecionado. Hand é indicado temporariamente e Mouse retorna ao final dos eventos; seleção por área e arraste dos elementos continuam disponíveis.
- Ctrl/Cmd + gesto/roda e pinça reconhecida pelo navegador aplicam zoom no ponto do cursor.
- Nuvem ajustada à imagem de referência: base reta, lobo maior à esquerda e menor à direita; cores continuam personalizáveis e conexões seguem o novo contorno.
- Armazenamento fixo da v1.9.1 preservado.

## Touchpad

O navegador fornece eventos de rolagem, não contagem de dedos. Eventos em pixels navegam; alguns mouses com rolagem suave também seguem esse comportamento. Use Ctrl + roda ou os botões +/− para zoom. A indicação temporária de Hand termina após a pausa dos eventos (a inércia pode continuar após tirar os dedos). Painéis de edição e textos com rolagem não movem o mapa.
