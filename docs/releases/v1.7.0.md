# Painel Ping v1.7.0 — Cartões e mapa no menu lateral

## Novidades

- A visualização principal volta a ser **Cartões**, com status ICMP, latência, perda, disponibilidade, histórico recente e acesso aos detalhes de cada dispositivo.
- Menu lateral retrátil com as seções **Cartões** e **Mapa**. A preferência de largura do menu fica no navegador; em telas estreitas, as seções são exibidas em uma barra horizontal.
- Os cartões permitem buscar dispositivos, filtrar pelo status e solicitar uma atualização. Problemas aparecem primeiro.
- O mapa conserva sua edição local ao navegar para Cartões. O modo TV em tela cheia continua exibindo apenas o mapa, inclusive quando iniciado a partir da visualização por cartões.

## Atualização

Faça backup de `.env` e `backend/storage` antes de substituir a versão. Extraia o ZIP, restaure os arquivos e execute `npm install` e `npm run dev`. Para produção: `npm run build` e `npm start` com `NODE_ENV=production`. Requer Node.js >=22.12 e o utilitário ping instalado.

Esta versão não altera o formato dos dados armazenados. Se editar o mapa, clique em **Salvar mapa** antes de fechar a página.
