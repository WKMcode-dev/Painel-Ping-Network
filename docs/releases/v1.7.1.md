# Painel Ping v1.7.1 — Modo TV acompanha Cartões ou Mapa

## Correção

- A tela cheia mostra a seção ativa: **Cartões** se o operador estiver em Cartões, **Mapa** se estiver em Mapa.
- Na TV, somente o conteúdo da seção ocupa a tela. Os cartões recebem atualizações em tempo real, respeitam o setor e os filtros ativos e não abrem janelas de detalhes durante a apresentação.
- **Esc** ou **Sair do modo TV** retorna à seção original. A rotação de setores configurada funciona nos dois modos.

## Atualização

Faça backup de `.env` e `backend/storage` antes de substituir a versão. Extraia o ZIP, restaure os arquivos e execute `npm install` e `npm run dev`. Para produção: `npm run build` e `npm start` com `NODE_ENV=production`. Requer Node.js >=22.12 e o utilitário ping instalado. Os dados persistidos não mudam de formato.
